# Клава — температурный фон

Интерактивный HTML-прототип мобильной клавиатуры. Чем быстрее вводишь текст, тем теплее становится фон: от синего через розовый до оранжевого. Во время паузы фон плавно охлаждается, а тёмная область продолжает перетекать.

Прототип центрируется в окне и уменьшается, если не помещается по высоте. Прозрачные клавиши используют простую белую заливку 20% и подсветку при нажатии.

## Открыть

Откройте `index.html` в браузере — сборка и установка зависимостей не нужны. Все изображения встроены в файл.

Публичный прототип на GitHub Pages: [открыть](https://kremlyov.github.io/klava-thermal-gradient/).

## Редактировать

- `source/keyboard.html` — разметка, стили, анимация и логика ввода.
- `source/assets/` — локальные изображения и иконки макета.
- `source/page-shell.html` — оболочка страницы.
- `scripts/build.py` — сборка одного HTML-файла со встроенными ресурсами.

После правок выполните:

```sh
python3 scripts/build.py
```

Для локального просмотра через HTTP:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

Верхняя часть переписки — изображение из исходного макета; поле ввода и клавиатура работают. Введённый текст обрабатывается локально в браузере и не сохраняется на сервере.
